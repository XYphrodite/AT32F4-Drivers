# AT32F4-Drivers Library

[English](README.md) | **Русский**

Общая библиотека ядра для проектов на микроконтроллерах AT32F403A/AT32F407.

## Обзор

AT32F4-Drivers — это уровень аппаратных абстракций (HAL) и набор драйверов, предоставляющий единый интерфейс для периферии микроконтроллеров AT32. Библиотека используется совместно в нескольких проектах прошивок.

## Поддерживаемые микроконтроллеры

- **AT32F403A** — основная цель (AT32F403ACGT7/AT32F403ACGU7)
- **AT32F407** — вторичная цель

Оба МК основаны на ядре ARM Cortex-M4F с FPU.

## Состав библиотеки

### Поддержка ядра МК (`AT32F403A/`)
- **CMSIS** — ARM Cortex Microcontroller Software Interface Standard
  - Определения ядра и стартовый код
  - Заголовки устройств и инициализация системы
- **Drivers** — драйверы периферии (51 файл)
  - GPIO, UART/USART, I2C, SPI, ADC, DMA, Таймеры
  - CRM (управление тактированием и сбросом)
  - Контроллер Flash-памяти
- **Linker Scripts** — описание раскладки памяти для AT32F403AxG
- **SVD** — System View Description для отладки
- **Startup** — стартовые файлы на ассемблере

### Middleware (`Middlewares/`)

#### FreeRTOS (769 файлов)
- **Версия:** операционная система реального времени
- **Кучи:** настраиваемые (Heap_1 … Heap_5)
- **Порты:** GCC_ARM_CM4F
- **Конфигурация:** проектный `FreeRTOSConfig.h`
- **Использование:** включен в прошивке lite-gateway

#### USB стек (42 файла)
- **Классы устройств:**
  - USB Virtual COM Port (CDC)
  - USB WinDriver
- **Возможности:**
  - Full-speed USB 2.0
  - Вендор-специфичные протоколы
- **Использование:** отладка и интерфейс связи

#### Segger RTT (14 файлов)
- **Real-Time Transfer** для отладочного вывода
- **Возможности:**
  - Высокоскоростное логирование
  - Минимальная нагрузка на CPU
  - Поддержка JLink
- **Использование:** отладочная печать без UART

### Общие библиотеки (`Library/`)

#### Связь
- **UART/USART** — драйверы последовательной связи
  - `UartDrv.cpp/.h` — низкоуровневый драйвер
  - `UartApi.cpp/.h` — высокоуровневый сервис
  - `UartStrBuf.cpp` — утилиты строковых буферов
  - Кольцевой буфер с поддержкой DMA
  - Настраиваемая скорость (по умолчанию 115200)

#### Протоколы и кодирование
- **CayenneLPP** — кодирование Low Power Payload
  - Стандартный формат данных LoRaWAN
  - Кодирование TLV (тип-длина-значение)
  - Поддержка температуры, напряжения, GPS, акселерометра

#### Системное управление
- **UnitControl** — управление устройством и конфигурация
  - Управление питанием
  - Автомат состояний системы
  - Сохранение конфигурации

#### Утилиты
- **Timers** — аппаратные и программные таймеры
- **GPIO** — абстракции управления пинами
- **ADC** — аналого-цифровое преобразование
- **I2C/SPI** — протоколы шин
- **Watchdog** — надёжность системы
- **RTC** — часы реального времени

## Интеграция со сборкой

### Конфигурация CMake

Каждый проект подключает AT32F4-Drivers так:

```cmake
set(SHARED_LIB_PATH ${CMAKE_CURRENT_SOURCE_DIR}/../AT32F4-Drivers)
```

### Определения компилятора

Стандартные дефайны для проектов AT32:
```cmake
-DAT32F403ACGT7      # Целевой МК
-DUSE_STDPERIPH_DRIVER
```

### Пути подключения

Проекты автоматически подключают:
- `AT32F403A/cmsis/cm4/device_support/`
- `AT32F403A/drivers/inc/`
- `Library/` (разные подкаталоги)

## Примеры использования

### Инициализация UART
```cpp
#include "UartApi.h"

usart_init_type uart_config = {
    .usart = USART1,
    .baudrate = 115200,
    .data_bit = USART_DATA_8BITS,
    .stop_bit = USART_STOP_1_BIT,
    .parity = USART_PARITY_NONE,
    // ... дополнительная конфигурация
};

UartService::Init(&uart_config);
```

### Задача FreeRTOS
```cpp
#include <FreeRTOS.h>
#include <task.h>

void myTask(void *parameters) {
    for (;;) {
        // код задачи
        vTaskDelay(pdMS_TO_TICKS(100));
    }
}

xTaskCreate(myTask, "myTask", 256, NULL, tskIDLE_PRIORITY + 1, NULL);
```

## Важные замечания

⚠️ **Предупреждение о legacy-версии:**  
Это старая/кастомизированная версия AT32F4-Drivers, поддерживаемая специально для этого проекта. Будьте осторожны при интеграции новых версий библиотеки — возможны проблемы совместимости.

### Известные модификации
- **UnitControlWave** отключён в LBS (LoRaWAN Basic Stack)
- Кастомные конфигурации периферии для AT32F403A
- Адаптации middleware под проекты

## Требования к памяти

Типичный отпечаток:
- **Flash:** ~100-200 КБ (зависит от включённых фич)
- **RAM:** ~20-50 КБ + куча FreeRTOS (если используется)
- **Stack:** настраивается на задачу (FreeRTOS) или ~2 КБ (bare metal)

## Требования к компилятору

- **Тулчейн:** ARM GCC (arm-none-eabi-gcc)
- **Стандарт C:** C11
- **Стандарт C++:** C++20
- **Оптимизация:** -O2 (Release), -Og (Debug)
